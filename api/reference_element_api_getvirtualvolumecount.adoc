= GetVirtualVolumeCount
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
È possibile utilizzare il `GetVirtualVolumeCount` metodo per recuperare il numero di volumi virtuali attualmente presenti nel sistema.



[[parameters]]
== Parametri

Questo metodo non ha parametri di input.



[[return-value]]
== Valore restituito

Questo metodo ha il seguente valore restituito:

|===
| Nome | Descrizione | Tipo 


 a| 
conta
 a| 
Il numero di volumi virtuali attualmente presenti nel sistema.
 a| 
intero

|===


[[request-example]]
== Esempio di richiesta

Le richieste per questo metodo sono simili all'esempio seguente:

[listing]
----
{
  "method": "GetVirtualVolumeCount",
    "params": {
    },
    "id": 1
}
----


[[response-example]]
== Esempio di risposta

Questo metodo restituisce una risposta simile all'esempio seguente:

[listing]
----
{
  "id": 1,
  "result": {
    "count": 5
  }
}
----
